# Arc 한국어 빌드 가이드

Foundry를 이용해 Arc Testnet에 첫 Solidity 스마트 컨트랙트를 배포하는 한국어 초보자 가이드입니다.

## 링크

- [한국어 가이드](https://arc-korean-build-guide.sdg7929.chatgpt.site)
- [Arc 공식 Deploy on Arc 문서](https://docs.arc.io/arc/tutorials/deploy-on-arc)
- [Arc 공식 홈페이지](https://www.arc.io/)

## 다루는 내용

- macOS, Linux, Windows WSL 실행 환경 준비
- Foundry 설치 및 기본 Counter 프로젝트 생성
- Arc Testnet RPC 연결과 로컬 테스트
- 테스트 지갑 생성 및 Faucet에서 테스트넷 USDC 받기
- Counter 컨트랙트 배포와 소스 코드 검증
- `cast call`, `cast send`를 이용한 컨트랙트 실행
- 초보자용 문제 해결

## Arc Testnet 정보

| 항목 | 값 |
